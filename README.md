# Particle Algorithm

Interactive particle animation written in vanilla JavaScript and Canvas.

## Features

- Dynamic particle simulation
- No framework, pure HTML/CSS/JS

## Tech Stack

- HTML/CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/javascript-particle-algorithm.git
cd javascript-particle-algorithm
npm install
npm start
```

Other scripts:

- `npm run build`: echo This is a static template, there is no bundler or bundling involved!
